# Support

- **Questions and ideas** → [Discussions](https://github.com/open-coder-ai/context-report/discussions).
  Telling us what's confusing *is* a contribution.
- **Bugs** → [open an issue](https://github.com/open-coder-ai/context-report/issues/new/choose) with a
  reproduction. The failing command's output and your `python --version` help a lot.
- **Security vulnerabilities** → [private security advisory](https://github.com/open-coder-ai/context-report/security/advisories/new),
  never a public issue. Details in [SECURITY.md](SECURITY.md).
- **Docs** → start at the [README](README.md) and the schema at
  [`spec/attestation/v0.1/schema.json`](spec/attestation/v0.1/schema.json).

There is no paid support or SLA; this is an open-source project. Maintainers aim to give
first feedback on issues and PRs within a few days.
